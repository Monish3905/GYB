# UK ? India Production Path

To transition this corridor from SANDBOX to PRODUCTION, GYB must complete:
1. Legal Entity & FCA Authorization
2. Onboarding with a UK PSP for GBP Collection (e.g., Modulr, ClearBank).
3. Onboarding with an Indian PSP for INR Payout (e.g., Cashfree, Razorpay).
4. Obtaining live API keys (stored in Vault).
5. Passing Maker/Checker Four-Eyes approval for the first pilot transactions.
6. Enabling REAL_MONEY_ENABLED=true.
